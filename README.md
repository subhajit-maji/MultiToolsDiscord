A versatile Python-based Discord bot framework that offers a collection of tools and utilities to enhance your Discord server's functionality.

---

## 🚀 Features

- **Modular Design**: Easily extendable with cogs for additional features.
- **Customizable Configuration**: Adjust settings via `config.json`.
- **Content Moderation**: Includes a list of forbidden words in `mots_interdits.json`.
- **Python 3.6+ Compatible**: Developed using modern Python practices.
